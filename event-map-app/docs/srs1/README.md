# СРС №1 — презентация

## Готовые файлы

- `СРС1_Фамилия_Имя_Группа.pptx` — 17 слайдов, формат 16:9.
- `СРС1_Фамилия_Имя_Группа.pdf` — PDF-версия для загрузки в Moodle.
- `assets/architecture.png` — архитектурная схема.
- `assets/er.png` — ER-модель.
- `assets/screenshots/*.png` — фрагменты HTTP-ответов для слайда 15.
- `build_presentation.py` — генератор PPTX, PDF и изображений.

## Перед сдачей

1. Переименовать файлы: `СРС1_<Фамилия>_<Имя>_<Группа>.pptx/.pdf`.
2. На титульном слайде заменить `Фамилия Имя, группа ____`.
3. На слайде 16 вставить ветку и SHA последнего коммита.
4. Добавить ссылку на Kanban-доску (в презентации или отдельным сообщением).
5. При необходимости заменить скриншоты на реальные снимки окна терминала/Postman.

## Пересборка

```bash
python docs/srs1/build_presentation.py
```

Скрипт использует `python-pptx`, `Pillow` и `reportlab`; шрифты Arial/Consolas
берутся из `C:/Windows/Fonts`.
